How this maps to the Producer–Consumer problem

  • Producers: the three sensors generate alerts and push them into the buffer.
  • Shared bounded buffer: a FIFO array with a maximum of 5 pending alerts.
  • Consumers: two emergency-response workers pull alerts and handle them.
  • Mutual exclusion: a lock makes sure only one consumer claims an alert at a time.
  • Buffer overflow: new alerts are rejected with a message when all 5 slots are used.
  • FIFO order: the oldest alert (ROOM 101 first in the sample) is always processed first.

⚠ Note: browser JavaScript is single-threaded, so Worker 1 and Worker 2 are simulated workers. This is a UI demonstration of the OS concept (synchronisation shown with a simple lock variable), not real operating-system threads.
